# Poketch

Poketch is a non-commercial, unofficial Pokémon fan project built with Expo and React Native. It is a personal project created for learning and for the enjoyment of Pokémon games.

## Features

- Pokédex browsing for Pokémon #001–#649
- Pokémon detail screens
- Animated and static sprite assets
- Mobile-first navigation powered by Expo Router

## Getting started

```bash
npm install
npm run start
```

The Pokémon assets used by the app are included in this repository so the project can be run without downloading them separately. The original download script is retained at `scripts/download-pokemon-assets.mjs` for provenance and reproducibility.
